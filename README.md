# Python Expense Tracker

## Project Overview
The Python Expense Tracker is a simple command-line application developed to help users record, view, and calculate their daily expenses.

The main purpose of this project is to make expense management easier by allowing users to maintain a list of their spending directly through the Python terminal.

"This project was developed for learning and practicing core Python programming concepts."

## Use Case
The application helps users keep track of their daily spending and understand how much money they have spent.

For example, if a user spends money on food, transportation, shopping, or other activities, they can add each expense to the tracker and view their recorded expenses whenever needed.

## How It Works

1. **Start the Application:** The program displays a welcome message and a menu of available options.
2. **Add Expense:** The user enters expense details such as date, category, description, and amount.
3. **View Expenses:** The application displays all previously recorded expenses.
4. **Calculate Total:** The program calculates and displays the total amount of recorded expenses.
5. **Exit:** The user can exit the application through the menu.

## Project Limitations
- The application runs only in the Python terminal.
- Expense records are stored temporarily in memory.
- Data is not permanently saved after the program closes.
- It does not use a database or graphical user interface.
